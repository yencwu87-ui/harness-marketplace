Install the skills

Run these on your own computer. Both come from your public repos on GitHub.

1Harness Marketplace (in Claude Code)
/plugin marketplace add yencwu87-ui/harness-marketplace
/plugin install harness-audit@harness-marketplace
/plugin install harness-init@harness-marketplace
/plugin install harness-core@harness-marketplace
/plugin install harness-redteam@harness-marketplace
2Agent Company (Terminal)
git clone https://github.com/yencwu87-ui/agent-company.git
cd agent-company
python3 agent_company.py launch
3Suggested order for a repo

audit → init → core → redteam → audit again (from the marketplace README).
